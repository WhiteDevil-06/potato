# POTATO.EXE

A highly customized, interactive, and slightly chaotic web-experience designed as a digital birthday gift for an elder sister (aka "Potato"). 

Built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, the site acts as an overarching "system intercept" that forces the user through a guided, emotional, and heavily sarcastic digital journey.

## 🚀 Features

*   **Terminal Override Sequence**: An automated fake terminal boot sequence that identifies the user through various aliases (Potato, Drama Queen, Peddhu, Dumbso).
*   **Memory Archive**: A fully responsive masonry grid displaying 45 curated images, each with a unique, tailor-made caption highlighting classic sibling dynamics.
*   **Dynamic Teasing Engine**: A randomized system that pulls from her known aliases to generate playful insults perfectly placed to bridge the gap between sections.
*   **Hostility Protocol (Argument Simulator)**: An interactive component that forces the user to initiate a fake argument (e.g. "Unnecessary teasing", "Pointless issue") before they can progress. It outputs a fake win/loss probability and ultimately "restores the bond".
*   **Cinematic Core Memory Decryption**: A heavily stylized, sentence-by-sentence text decryption sequence hidden behind a flashlight interaction effect.
*   **Relationship Archive Receipt**: The final unlock—a highly stylized digital receipt featuring a playing video memory, confetti physics, and a heartfelt message.

## 🛠️ Tech Stack

*   **Framework**: [Next.js](https://nextjs.org/) (App Router)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Animation**: [Framer Motion](https://www.framer.com/motion/)
*   **Effects**: `canvas-confetti`
